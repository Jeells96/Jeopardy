# 🎄 Christmas Jeopardy 🎅

A show-style, real-time game night for a Christmas party — **Husbands vs Wives** by
default. Play **mini games** for team points, then **Jeopardy**: everyone buzzes in from
their own phone, with a projector board and a private **host screen** (on your phone or
laptop) with the answer key and every control. Finish with an **ugly sweater vote**.

**Live site:** https://Jeells96.github.io/Jeopardy/

---

## ⚡ Host quick start (game night)

1. **Projector:** open **📺 Board** on the projector computer. It only ever shows what
   you've started — the lobby, the mini games or the Jeopardy board — never answers.
2. **You:** open the site, tap **Host login**, enter **2325**. Host and Remote are the same
   private screen: the answer to every question, who's buzzed, wagers, and all the
   buttons. Keep it to yourself and host from anywhere in the room.
3. **Sound:** every screen plays every sound — the board, your host screen and all the
   players' phones. Sound is on by default; 🔊/🔇 turns it off on one screen, and a refresh
   turns it back on. Browsers need one tap on a page before it can make sound, so tap the
   board once (it shows **👆 Tap to start sound** until you do).
4. **Players** scan the QR code on the lobby screen, type their name, pick **Husbands**
   or **Wives** and tap **Join & turn on sound** (one tap joins and starts their phone's
   sound). (A team can rename itself from a phone.) A first name on its own is fine —
   **unless someone already has it**: then their phone says "🎅 Santa already has someone
   called Mike on his list" and they can't join until they add a last name or an initial
   ("Mike B."), so nobody is confused when the board says who buzzed in.
5. **Follow the gold button.** It always shows the next step (keyboard: **Space**):
   mini games first if you've set any up, then Jeopardy.

**Practice first:** ⚙ Settings → Questions → **🧪 Put the test game on the board** loads a
one-category, non-Christmas game (plus a multiple-choice Final) so you can try every
feature without seeing the real questions. When you're done, open the question library and
tap **▶ Use in the game** on your real set.

## 🎯 Mini games (before Jeopardy)

Set them up in **⚙ Settings → Mini games**: type a name and tap **+ Head-to-head**,
**+ Best overall** or **+ Everyone at once** (or tap one of the ready-made ideas). Each game
has its own point value, a **⏱ Timer** and a **⏩ Two tables at once** tick box, and the
points go straight onto the team's score and carry into Jeopardy.

| Type | How it plays | What you do |
|---|---|---|
| ⚔️ **Head-to-head** | One husband faces one wife each round | Tap who won (keys **1** / **2**, **T** for a tie) |
| 🏅 **Best overall** | Everyone takes a turn; best single score wins it for their team | Type each score and press Enter |
| 🏆 **Everyone at once** | The whole room plays at the same time — no draws, no scores | Tap who won (keys **1** / **2**, **T** for a tie) |
| ✏️ **Blind drawing** | Everyone draws at once and the website scores every drawing; scored like Best overall | Nothing — it scores itself |

- **Who's up next?** Press the gold button and the big screen shuffles through the names,
  lands on the pick with a drum-roll, and **says it out loud** ("Up next: Jake versus
  Sarah!"). The picked players' phones buzz with **You're up!**
- **Fair rotation:** a player leaves the "still to play" pool the moment they're picked (a
  re-draw puts them back), so nobody is drawn twice until everyone on their team has had a
  go, and the shuffle only shows names still in the pool. Across the night, people who
  haven't played any mini game yet are picked first. Uneven teams are fine. With an odd
  number of couples at two tables, the **spare table waits** rather than calling someone up
  twice — tap **🎲 Draw for [table]** if you'd rather start the next round there anyway.
- **Don't like the draw?** Tap 🎲 to re-draw one side, or choose a person from the list.
- **🏆 Who won it?** On an **Everyone at once** game your controls list everybody as a tap:
  tap the person who won and their **team gets the points** and **they** get the win toward
  🏆 North Pole Champ (the board says "Won for the Wives by Liz Eells"). There are still
  plain **🏆 Husbands / 🏆 Wives (whole team)** buttons when nobody stood out.
- **⏱ Played against the clock?** Tick **⏱ Timer** on the game in Settings → Mini games and
  type the seconds (it shows you the time, e.g. `0:45`). **You** start it: your controls get
  **⏱ Start the timer (0:45)** (keyboard **K**). The countdown then shows big on the
  projector and on **every phone**, all off the same clock — so however many tables are
  playing, they're all playing to the **one timer**. When it runs out, the **horn sounds on
  every screen at the same moment** and everything says **📣 TIME'S UP!**. **⏹ Stop** cancels
  it, **↻ Restart** puts it back on for the next pair, and the clock clears itself when the
  game finishes. (Blind drawing doesn't use it — it has its own step clock.)
- **Points:** head-to-head games can give the points to the team that wins the game, or
  *for every matchup win*. Best-overall games can be highest-wins or lowest-wins (fastest
  time), with a unit like "seconds" — and the points go to the team **the overall winner
  plays for**.
- **Finishing:** the game suggests the winner from what you tracked; you can overrule it,
  call a **tie** (points split) or give no points. You can also skip the tracking entirely
  and just declare who won.
- **Started a game by mistake?** **↶ Undo start** in your controls puts it back to "Not played
  yet" and takes you back to the games list (any points it gave out are taken back).
- **Fixing mistakes:** remove a wrong result with ✕, **Undo** the last points, or **↺ Reset**
  a game to hand its points back.
- **No phone?** Add people by hand in **Settings → Players** (first and last name) — they're
  drawn like anyone else.
- **💍 Couples play each other:** in **Settings → Players**, give each couple a number — the
  husband is **1a**, his wife **1b**, then 2a / 2b, and so on (the box in front of each name).
  Head-to-head games then draw a **couple** each time: pick one of them and their other half
  is the other side, and they're summoned to the same table together. 🎲 re-drawing one half
  brings their partner along. Anyone who came on their own is still drawn, against whoever
  is free, and the Players tab flags a number that's missing its other half. Switch it off
  with **Couples face each other** at the top of the Players tab.
- **⏩ Two tables at once (to get through the games faster):** every head-to-head and
  best-overall game has a **⏩ Two tables at once** tick box in Settings → Mini games — that's
  where you say a game is played at more than one table. Ticked, it runs at **both tables at
  the same time**: one draw puts a different matchup (or player) at every table — nobody is
  drawn for two tables — and the board, the phones and the announcer tell everyone which
  table they're summoned to, with a different Christmas summons every time. Your controls
  show a row per table: tap who won (or type the score) for each table as it finishes, then
  **🎲 Draw for [table]** refills just that table. 🎲 re-draws a table; ✏️ lets you swap a
  player or move a matchup to another table. While you play, **+ Add table** next to the
  draw button goes up to 8, and ✕ takes one away (a table someone is playing at can't be
  removed until it's free). Each game remembers its own setting, and **Everyone at once**
  and **Blind drawing** have none — the whole room plays those together.
- **Mid-game bonus round:** Settings → Jump to → **Mini games** pauses Jeopardy; the gold
  button brings you back to the same board.

### ✏️ Blind Drawing
Add it from **Settings → Mini games → ideas** — it's a once-a-night game, so there can only
be one. The website scores every drawing 0–100% and the **best drawing of the night wins the
points for its team**, scored like a Best overall game.
1. **Pick the pictures:** under the game, tap **🎄 Ready-made drawings** and choose from 10
   Christmas pictures (snowman, gingerbread man, Santa, reindeer, decorated Christmas tree,
   snowy cottage, stocking, penguin in a Santa hat, hot cocoa, stack of presents), each built
   up in exactly 10 finger-friendly steps (no tiny details). Or tap
   **✍️ Draw my own** and type how many steps you'll describe. Each round uses the next picture.
   Set how many seconds each step lasts ("New step every … seconds", default 20).
2. **Play — everyone at once:** tap **✏️ Everyone draw!** and every phone's **whole screen**
   becomes a drawing pad (the page can't scroll, zoom or swipe away while it's up). Everyone
   draws at the same time, right where they're sitting (no tables, nobody is picked). The pad
   stays off while people put their phones on top of their heads, so that leaves no marks.
   Tap **▶ Start drawing** when phones are on top of heads. After a 3-second
   countdown the big screen shows **Step 1 of 10: "Draw a big circle…"** with an example of what
   the drawing should look like so far (the new step in red), and moves to the next step
   every X seconds. Phones show the step number and buzz on each new step. For a
   picture you drew yourself, the screen shows "Step 2 of 4 — listen to Jaren" (no example),
   and your screen shows the picture so you can describe each step.
3. **Pencils down:** the last step lasts **twice as long**, to finish off. Then the pads
   switch off and every drawing **sends itself** — nobody has to press anything, and nobody
   can touch up their drawing once they look at it. Each phone then shows **the drawing it
   sent**. (Nothing is sent while they draw, so nothing lags; each drawing is saved on its
   own, so 30 phones sending at once never clash.) The big screen ticks off each drawing as
   it comes in.
4. **The website judges** every drawing as soon as they're all in — position, size, rotation
   and mirror image don't matter, and a few stray lines are forgiven. The big screen shows
   **the picture, the winner and last place** side by side with a % match, and the tally
   underneath is each team's **best drawing so far**. Each phone says how that player did ("You came 2nd
   of 9"), shows their own drawing, and has the **full leaderboard** — tap anyone to see
   their drawing (or the original picture). **⏭ Judge now** judges straight away if someone
   never sends (no drawing = last).
5. **Another round** uses the next picture, or **🏁 Finish game**: the points go to the team
   with the **best drawing of the night**.
- **↶ Undo round** throws a round away as if it never started (the same picture comes up next).
- Only players with a phone draw; anyone who joins before you tap Start draws too.

### Team names
Teams start as **Husbands** and **Wives**. Until Jeopardy starts, anyone on a team can tap
**✏️ Rename our team** on their phone. You can always rename teams in Settings → Game, and
switch off phone renaming there too.

## 🎮 Everything that's in the game

**The board**
- One Jeopardy round ($100–$500) + **Final Jeopardy**. (There's no Double Jeopardy round —
  older sets that had one keep those questions in a separate "– extra categories" set.)
- **Board control:** the team that answered correctly picks next (shown on the board and
  phones). While a team picks, **every phone shows what's left on the board** ("🎁 Still under
  the tree — 12 questions"), so nobody has to squint at the TV to choose (Daily Doubles stay
  hidden, of course).
- **Scores float up** ("+$200" / "−$100") from the podiums and from every phone's score
  chips the moment they change, in time with the sound.
- Questions zoom in full-screen; categories, values and podium scores styled like the show.

**Buzzing**
- **The fastest press wins — not the fastest Wi-Fi.** When Jaren opens the buzzers they
  light up a moment later, at the same instant on every phone and the board (by a shared
  clock every screen keeps in step with the server). Each press is stamped with that clock
  the instant it happens, and the earliest press wins, even if a slower phone's message
  arrives later. (A host screen waits 0.6 s after the first press for any slower phones,
  then locks it in; with no host screen open, the buzzing phone does it.)
- **Pressing too soon** — while the question is read, or before the buzzer turns green —
  locks you out for a quarter second, like the real show.
- The board, Jaren and the phones show **reaction times** to the hundredth of a second
  ("⚡ Amy 0.21s · Bob 0.27s"), so everyone can see it was fair.
- Built for a crowd: every press is its own little record, so 30 phones buzzing at once
  never get in each other's way.
- The buzzer locks for everyone once it's decided. Each team's phones show a
  Christmas pun — "we're counting on you" for the buzzer's team, a playful roast for the
  other team — and every member of a team sees the same one.
- **Rebound:** after a miss the other team can buzz in right away (can be turned off). Every
  phone says what happened: "🥶 Brrr — not quite! (−$200)" on the phone that missed,
  "🥶 Amy missed" for her teammates, and "🎁 Amy missed — your turn to steal it!" for the
  other team.
- Optional **buzz-in window** (nobody buzzes in time → answer revealed) and optional
  **auto-open** of buzzers after a reading delay.
- Phones buzz on touch-down for speed, vibrate when buzzers open / when you're up, and
  stay awake during the game.
- **Lost connection?** A screen that can't reach the game shows "❄️ Lost the signal to the
  North Pole — reconnecting…" (phones add that buzzes won't count until they're back), and
  "🎄 Back online" when it is, so nobody buzzes into the void without knowing.

**Answering**
- **Typed answers:** whoever wins the buzz gets a text box, already open and ready to
  type. Their answer appears on the board and your screen says whether it matches. You tap
  Correct / Wrong / Skip.
- **Multiple choice:** every phone shows the options along with the question (nobody has to
  look at the TV). Whoever buzzes in taps an option and it's scored automatically. A wrong
  option is crossed off for the rebound team. Questions can have **2, 3 or 4 options** (one
  right answer plus 1–3 wrong ones), and the options are always put in a **random order** when
  the questions go on the board, so the right answer isn't always first (or anywhere in
  particular). With 3 options the third sits centred under the other two.
- **🎁 Take away a wrong answer** (key **H**) — a 50/50 for the room. Tap it and the game
  crosses off one **wrong** option at random, on the board and on every phone; it can't be
  tapped any more. Tap it again for another, down to the **last two** (the right answer is
  never taken, and the button disappears at two). It's there while the question is read,
  with the buzzers open, on a rebound and while someone's answering — and the button says
  how many options are left. Put the question back and it starts again with all of them.
- **The result on every phone:** "🎅 Ho ho ho — you got it! +$200 for your team" on the phone
  that answered (with a happy buzz — or a sad one for a miss), "🎄 Amy got it for your team!"
  for teammates, and "🥶 Amy got it — Wives +$200" for the other team, plus the answer.
- **Answer timer** with show-style countdown lights. **Out of time is your call:** the
  time's-up bell rings and the answer box (and the multiple-choice options) close on their
  phone, but **no points come off** until you decide. Your controls say
  **"Late answer — Liz ran out of time"** with three buttons: **✓ Allow it** (full points,
  if they blurted it out just after the bell), **✗ Too late** (points off — and it goes down
  as unanswered, not a wrong answer) or **Let them off** (no points either way). Nothing
  buzzes a second time. After "Too late" or "Let them off" the other team gets
  **30 seconds to steal** (Settings → Game → Steal time). If nobody buzzes in, the answer
  is shown and nobody loses points.

**Daily Doubles**
- Splash screen and sound, no buzzing — the team that found it plays.
- **The wager is entered on a phone:** anyone on the team that found it can type it in and
  lock it (the first one locked counts). Jaren can still enter it for them.
- Wager **$5 up to everything the team has**. At $0 or below, they can wager up to the
  board's top value ($500), like the show. Quick buttons for min / half / **"All in!"**.
- **30 seconds to answer** (Settings → Game → Timers → Daily Double), however short the
  normal answer time is.

**Final Jeopardy**
- **Fix up the scores first** if you need to: when the board is clear, and while wagers are
  being made, your controls show both scores with ✏️ to adjust them (who plays and the
  wager limits follow).
- Only teams above $0 play (official rule — you can override per team).
- Teams **lock their wager secretly on their phones** (teammates see it, the other team
  and the projector don't). You can also enter wagers by hand.
- Think music + timer: **62 seconds — the song played twice**, and it always runs to the
  end (Settings → Game → Timers → Final Jeopardy). One answer per team: whoever submits
  first submits it for everyone, and any teammate can **Undo & change it** until time's up.
  If the Final has wrong options it's **multiple choice** and they tap one.
- **You read each answer first and make the call.** When time's up, your private screen
  shows the first team's answer and their wager with **✓ Correct** / **✗ Wrong**; the board
  keeps it hidden and just says "🤫 Jaren is reading the Husbands' answer…". Your verdict is
  what puts their answer, wager and new score on the board — then the next team, lowest
  score first. Nothing is ever marked by the website, multiple choice included.
- Winner screen with confetti.

**Host tools**
- **Picked the wrong question?** **↩ Oops — wrong question, put it back** (key **B**) puts it
  straight back on the board, unplayed — while it's being read, on the Daily Double screen,
  with the buzzers open, even while someone's answering. It's there right up until the
  question changes a score; anyone who buzzed can buzz again when it comes back up.
- **Undo** the last score change (U), adjust any score from its podium, switch who picks,
  jump to Final, new game.
- Rename or move players between teams (their phone updates instantly) or remove them —
  a removed player's phone is released and has to enter a name again to rejoin.
- Keyboard: Space next step · C correct · W wrong · S skip · N nobody · P pause buzzers ·
  R show answer · B put the question back · H take away a wrong answer · K mini-game timer ·
  U undo · M sound · F fullscreen · Esc close.

**🌟 The North Pole Awards (on the final-scores screen)**
- Under the winner, the board reveals the awards one after another, each on a gift tag with a
  candy-cane stripe and a bow:
  🧝 **Head Elf** (most right answers), 🦌 **Fastest Reindeer** (quickest winning buzz),
  💰 **Christmas Bonus** (most money won, when that's not the Head Elf again),
  🏆 **North Pole Champ** (most mini-game wins), 🎨 **Santa's Sketch Artist** (best Blind
  Drawing), 🪨 **Naughty List** (a lump of coal for the most wrong or unanswered questions —
  buzzing in and running out of time counts), and 🧶 **Ugliest Sweater** once
  the vote is done. An award only appears if someone earned it (and not when more than three
  people tie).
- Every phone gets a **"📜 Your Nice List report"**: right answers, misses, money won for the
  team, fastest buzz, mini-game wins and best drawing — then "🌟 You made the North Pole
  Awards!" with a gold tag for each award that player won — plus the full list of awards.
- It's all worked out from what happened, so **Undo** takes a result back out of the awards too.

**🧶 Ugly sweater vote (after Jeopardy)**
- On the final-scores screen tap **🧶 Ugly sweater vote**. You get the list of everyone —
  untick anyone who isn't in the running, then **Start voting**.
- Everyone votes on their phone (not for themselves) and can change their vote until the
  last one is in. The board shows only how many votes are in — nothing is revealed until
  every phone has voted (or you tap **Reveal now**). Then the winner gets the crown.

## 📝 Writing your questions — the Question library

Open **⚙ Settings → Questions → 📚 Open the question library** (or go to `#/questions`, host
code 2325). Every set of questions is kept there — one per year — so you can look back at
past years, search them, and reuse a good question.

- **+ New question set** — start empty, from what's in the game now, from the sample game,
  or from the **quick test game**: one non-Christmas category plus a multiple-choice
  Final, for trying out every feature without seeing the real questions.
- **📋 Paste questions** — mass input. Paste a whole batch and you see a live preview of
  what was understood before anything is saved. The tidiest format:

  ```
  == Jeopardy ==
  ## Christmas Movies
  100 | Who lives on Mount Crumpit? | The Grinch
  300 | Which store introduced Rudolph in 1939? | Montgomery Ward | Macy's; Sears; Woolworth's | DD
  ## History
  200 | Which president made Christmas a federal holiday? | Ulysses S. Grant
  == Final Jeopardy ==
  ## Famous Poems
  This 1823 poem begins 'Twas the night before Christmas | A Visit from St. Nicholas
  ```

  Each line is `points | question | answer`. A 4th part with wrong options (separated by
  `;`) makes it **multiple choice** (Final Jeopardy too: `question | answer | wrong; wrong`);
  `DD` marks a Daily Double; a 6th part is a host note.
  Leave points blank to fill them in automatically. It also understands
  `Question? Answer: X`, numbered lists with A) B) C) D) options, tables, rows copied
  from a spreadsheet, and JSON.
- **🤖 Ask AI for questions** — builds a request to paste into ChatGPT or Claude (number of
  categories, round, topics) that comes back in exactly the paste format, and tells it not
  to reuse answers from your past years.
- **Edit in place** — every question, answer, value and category is editable right on the
  page, and the boxes grow so you can read everything at once. **⋯** opens wrong options
  (multiple choice — with a switch to turn it off without deleting the options), Daily
  Double, round, a **host note**
  (shown only on your phone remote — e.g. "also accept St. Nick"), move, copy to another
  set, and delete (with Undo).
- **✂ Copy / move questions** — tap ✂ on any question (or **✂ All** on a category) to pick
  it, choose **Move** or **Copy** in the bar that appears, then tap **📥 Paste here** in any
  category, Final or Unsorted — or type a name and **Paste into a new category**. Works
  between sets too (e.g. copy last year's favourites into this year).
- **🗑 Delete a whole category** from its header (with Undo).
- **🎲 Shuffle into random categories** (above the Jeopardy round's categories): every
  question moves to a different category at random, and each new category gets one question
  from each old one. Every question **keeps its value** and everything else that goes with it
  (answer, options, Daily Double, note), and each category still runs $100–$500. The
  categories get **random Christmas names** ("Mistletoe Mixer", "Nog Brainers", "Sleigh
  What?", …) from a list of 120. **🎄 New random Christmas names** renames your groups without
  moving any questions. Both can be done again as often as you like, and **↩ Undo** puts the
  round back exactly how it was. Then tap **▶ Use in the game** to put it on the board.
- **♻ Also asked in Christmas 2025** — repeats from past years are flagged automatically.
- **🔎 Search every year** — questions, answers, categories and notes across all sets;
  copy any result into this year's set.
- **Readiness check** — what's still missing (unfinished questions, short categories, no
  Final Jeopardy, Daily Double count). The **Unfinished** filter shows only what needs work;
  half-written ideas are kept but never put on the board.
- **▶ Use in the game** — puts the set's finished questions on the board.
- **⋯ More** — download as a spreadsheet or text file, add questions from a spreadsheet,
  duplicate, **lock** a past year so it can't be changed by accident, delete.

The spreadsheet template still works (Settings → Questions → Spreadsheet) if you prefer it.
Questions live in Firestore under `state/set-*`, which the existing rules already allow.

## 🔊 Sound effects

Every screen with 🔊 on plays every sound, **in sync**: each sound is scheduled for the same
moment by the shared clock (0.65 s after it happens, so every screen has heard about it), and
each device takes its own speaker delay into account. The Final Jeopardy music is lined up
with the Final timer the same way. (A Bluetooth speaker can still add its own small delay.)

Built-in, original placeholder sounds play out of the box. To use your own audio, add MP3s
to the [`sounds/`](./sounds) folder with these exact names (any you skip keep the built-in
sound):

| Event | File |
|---|---|
| Correct answer | `correct.mp3` |
| Wrong answer | `wrong.mp3` |
| Time's up | `times-up.mp3` |
| Final Jeopardy think music (played twice) | `final-jeopardy.mp3` |
| Daily Double revealed | `daily-double.mp3` |
| Someone buzzed in | `buzz-in.mp3` |
| Board appears / new round | `board-fill.mp3` |
| Winner announced | `winner.mp3` |
| Mini games: drawing who's up next (~2 s) | `up-next.mp3` |
| Mini games: a team wins a mini game | `mini-game-win.mp3` |
| Mini games: the game clock runs out | `horn.mp3` |

> The official *Jeopardy!* sounds and music are copyrighted and aren't included. Use audio
> you have the rights to use.

## 🔥 Firebase setup (one time)

Firestore → **Rules**. This project shares Firestore with another app, so the rules are
combined — the Jeopardy part is the four `match` lines at the bottom:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    function contestLocked(contestId) {
      let contest = get(/databases/$(database)/documents/contests/$(contestId)).data;
      return contest.keys().hasAny(['lockAt']) && request.time >= contest.lockAt;
    }

    match /contests/{contestId} {
      allow read, write: if true;
      match /pool/{chunkId} { allow read, write: if true; }
      match /standings/{entryId} { allow read, write: if true; }
      match /entries/{entryId} {
        allow get: if true;
        allow list: if contestLocked(contestId);
        allow create, update: if !contestLocked(contestId);
        allow delete: if true;
      }
    }

    match /config/{document} { allow read, write: if true; }

    // ===== Christmas Jeopardy =====
    match /state/{doc}      { allow read, write: if true; }
    match /questions/{doc}  { allow read, write: if true; }
    match /players/{doc}    { allow read, write: if true; }
    match /buzzes/{doc}     { allow read, write: if true; }
  }
}
```

## 🛠 For developers

Static site, no build step. Firebase and SheetJS load from CDNs.

| File | What it does |
|---|---|
| `js/engine.js` | Pure game rules — every action is `(state, params) → changes` |
| `js/data.js` | Firestore I/O; runs engine actions inside transactions; server-clock sync |
| `js/app.js` | Routing, live subscriptions, rendering, actions, automations, sounds, typed answers |
| `js/summons.js` | Christmas summon lines for mini games played at several tables |
| `js/draw.js` | Blind Drawing: drawing pad, storage format and the shape judge |
| `js/pictures.js` | The 10 ready-made Christmas pictures, step by step |
| `js/ui/*.js` | Screens: `stage` (show display), `host`, `dock` (next-step logic), `remote`, `player`, `join`, `minis` (all mini-game screens), `team` (phone renaming) |

| `tools/cache-bust.sh` | Run by the deploy: adds `?v=<commit>` to every file URL |

**Updates reach open screens by themselves.** Every screen checks the page's Last-Modified
date every 90 seconds (and when a phone wakes up) and reloads onto a newer deploy — but never
while someone is drawing, typing, or in the middle of a question. The deploy workflow also adds
`?v=<commit>` to every file URL (`tools/cache-bust.sh`), so a phone never mixes cached old files
with new ones. (That part only applies when Settings → Pages → Source is "GitHub Actions".)
